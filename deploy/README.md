# Развёртывание BaqBaq — 23 сентября 2026

## Фактическое состояние

- Отдельный systemd-сервис `baqbaq`, непривилегированный пользователь `baqbaq`.
- Каталог `/opt/baqbaq/app`, своё venv, БД, uploads и кеш. Не использует чужие контейнеры или БД.
- Слушает только `127.0.0.1:8022`, один worker; MemoryMax 3G, CPUQuota 150%.
- Ключ находится в серверном `.env` с правами 0600; секреты не входят в репозиторий.
- Live `gpt-4.1-mini` + FastEmbed: синтетический smoke прошёл (4 вывода, вопрос, HTML).
- Оригиналы организатора не скопированы на сервер. Demo использует SYNTHETIC-файлы.
- Nginx-конфиги подготовлены, **не установлены и не активированы**. Существующие домены не менялись, Nginx не перезагружался.
- Авторитетный сервер `v0n0.nic.world` возвращает NXDOMAIN для baqbaq.world. Публичный HTTPS пока не работает.

## После исправления регистрации/делегирования

1. Убедиться, что A-записи baqbaq.world и www.baqbaq.world указывают на целевой сервер; проверить AAAA, если существует.
2. Проверить отсутствие существующего server_name и сохранить контрольные суммы чужих конфигов.
3. Установить только `nginx-http.conf` для baqbaq.world, выполнить `nginx -t`, затем graceful reload. HTTP не проксирует приложение и не запрашивает пароль.
4. Выпустить сертификат через certbot **certonly --webroot** с webroot `/opt/baqbaq/acme`, без автоматического редактирования чужих nginx-конфигов. Для www нужен отдельный успешный DNS-контроль.
5. Установить `nginx-https.conf`, проверить конфигурацию, затем graceful reload.
6. Проверить 401 без авторизации, успешный доступ с авторизацией, отказ неверному паролю, HTTP→HTTPS, сертификат и отсутствие прямого внешнего доступа к 8022. Проверить работу обновления сертификата и reload-hook.

HTTP Basic защищает весь демо-стенд, но не является многопользовательским IAM. Участники с общим паролем имеют общий доступ к демо. Только синтетические/публичные данные. Ограничения Nginx не заменяют отдельный лимит расходов OpenAI.

## Обслуживание и откат

- Статус: `systemctl status baqbaq`; перезапуск: `systemctl restart baqbaq` — только этот сервис.
- Проверка: `/opt/baqbaq/venv/bin/python /opt/baqbaq/app/deploy/smoke_live.py` (делает платные API-вызовы).
- Остановка: `systemctl stop baqbaq`; данные сохраняются.
- При будущем откате Nginx отключать только конфигурацию baqbaq.world, затем `nginx -t` и graceful reload. Не трогать другие сайты и общий default server.
- `prepare_env.py` — только первоначальная установка, отказывается перезаписывать существующий .env. Пароль демо генерируется случайно, не печатается.

Полный Live-анализ реальной пары, нагрузочные испытания и публичная HTTPS-проверка ещё не выполнены. Не объявлять домен доступным до их соответствующих проверок.
