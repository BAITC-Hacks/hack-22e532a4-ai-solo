# Развёртывание BaqBaq 0.3.0

## Граница доступа

- Публичный Live без пароля: главная сразу открывает загрузку двух редакций.
- BAQBAQ_PUBLIC_LIVE=1 и BAQBAQ_MODEL_MODE=live. Нужен серверный OPENAI_API_KEY.
- Сравнения изолированы случайной HttpOnly Secure cookie браузера. Старые приватные записи не раскрываются. Это не персональная учётная запись; при потере cookie сохранённые проверки не восстанавливаются через UI.
- Демо-маршруты отключены. Общие лимиты API сохраняются, но не гарантируют защиту от исчерпания бюджета посторонними.
- Конфиденциальные документы не загружать. Приложение слушает только loopback, наружу — Nginx HTTPS.

## Изоляция существующего сервера

Только /opt/baqbaq, systemd baqbaq, отдельный пользователь/venv/БД/uploads/cache, loopback 127.0.0.1:8022, один worker, лимиты памяти/CPU/concurrency. Nginx редактируется только для baqbaq.world; activate_nginx.py сверяет контрольные суммы остальных конфигов, выполняет nginx -t и graceful reload.

Ключ модели остаётся в серверном .env (0600). Исходные документы организатора на сервер не копируются.

## Обновление старого закрытого стенда

1. Сохранить backup кода, .env, своей SQLite и своего vhost в защищённом каталоге внутри /opt/baqbaq.
2. Проверить архив: никаких .env, uploads, пользовательских БД или путей за пределами приложения.
3. Обновить код и зависимости только своего venv.
4. Запустить configure_access.py: включается открытый Live и лимиты, существующий API-ключ не изменяется. Исторические auth-секреты сохраняются, но в публичном режиме не применяются.
5. Перезапустить только baqbaq. Проверить главную, health, отдельные cookie-пространства и отсутствие доступа к чужим сравнениям.
6. Если Nginx уже настроен без Basic Auth, не менять его. Первичная настройка — только собственный vhost, nginx -t и сверка других конфигов.
7. Короткая проверка: обычная загрузка двух небольших DOCX → Live → точные источники → решение → HTML. Не запускать полный платный прогон без необходимости.

Проверка не выводит пароли. configure_access.py предназначен для заданного VPS-пути, не для локального Windows.

## Проверки и обслуживание

- check_access.py сохранён для прежнего закрытого режима; для публичного Live используйте tests/test_public_live.py и браузерный сценарий.
- smoke_live.py — необязательный платный анализ небольшой синтетической пары через обычную загрузку, вопрос и HTML; создаёт отдельное сравнение. Не запускается автоматически при выкладке.
- systemctl status baqbaq / systemctl restart baqbaq — только этот сервис.
- Лимиты API по умолчанию: 200/сутки UTC и 80/задание; не долларовый бюджет.
- Прерванные задания после рестарта помечаются failed, повтор запускает новый анализ.
- Сертификат обслуживается отдельным certbot webroot; hook перечитывает Nginx только при обновлении сертификата BaqBaq.

## Откат

Вернуть только собственный код/.env и собственный vhost из backup, восстановить совместимые зависимости своего venv, проверить nginx -t, перезапустить baqbaq и перечитать Nginx. Не восстанавливать старую рабочую БД поверх новых документов без отдельного решения владельца. Не трогать чужие сайты, контейнеры, базы и default server.

Фактические результаты текущей выкладки: [проверка релиза](../results/RELEASE_VERIFICATION.md).
