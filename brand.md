# Brand — BaqBaq

_Status: active_

## Idea

BaqBaq combines restrained sumi-e brushwork with a precise digital dandelion: soft seeds represent semantic candidates, while crisp stems and seed bases represent exact evidence.

## Palette

- Workspace: `#F5F7F9`, white document surfaces
- Ink: `#182C38`
- Secondary ink: `#566773`
- Ochre / interpretation: `#A77A22`
- Teal / primary actions: `#176973`
- Rust / risk: `#9A4938`
- Night paper: `#171B19`

## Typography

- Headings and UI: Segoe UI / Arial / system sans. One family, compact hierarchy.
- Identifiers: Cascadia Mono / Consolas.

## Voice

Calm, evidence-first, precise. Never overstate absence as loss, similarity as duplication, or a model draft as a verified fact.

The supplied transparent BaqBaq wordmark is used once in the header, with no duplicate typeset name. Kazakhtelecom is identified as the hackathon track, not as an endorsement. Main workflow: upload both revisions → Live analysis → inspect exact sources → review → export.
