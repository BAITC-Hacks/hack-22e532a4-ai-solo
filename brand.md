# Brand — BaqBaq

_Status: active_

## Idea

BaqBaq combines restrained sumi-e brushwork with a precise digital dandelion: soft seeds represent semantic candidates, while crisp stems and seed bases represent exact evidence.

## Palette

- Washi paper: `#F4F0E6`
- Ink: `#202522`
- Secondary ink: `#555C58`
- Ochre / interpretation: `#A77A22`
- Teal / verified evidence: `#225E63`
- Rust / risk: `#9A4938`
- Night paper: `#171B19`

## Typography

- Headings: Georgia with local Cyrillic serif fallbacks.
- UI: Inter when locally available, then Segoe UI / system sans.
- Identifiers: Cascadia Mono / Consolas.

## Voice

Calm, evidence-first, precise. Never overstate absence as loss, similarity as duplication, or a model draft as a verified fact.
