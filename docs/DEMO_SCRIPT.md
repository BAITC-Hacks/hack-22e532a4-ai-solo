# Демо за 3 минуты

Сценарий показа открытого Live 0.3.0. Три минуты — время объяснения, не SLA расчёта. На домене и локально один интерфейс; пароль и демонстрационные кнопки убраны.

## 0:00–0:30 · Задача

Открыть baqbaq.world: «Анализ организационных изменений». Объяснить, что агент сверяет обязанности и владельцев, а не только удалённые строки. Загрузить разрешённые документы в «До изменений» и «После изменений». Для локального запуска заранее настроить API-ключ.

## 0:30–1:30 · Четыре проверяемых случая

Нажать «Запустить анализ». Дождаться фактического завершения. Выбрать найденное изменение в таблице: перенос, изменение или риск. Не обещать, что конкретный тип обязательно будет найден. Прочитать обе цитаты и границу вывода. У дубля обе цитаты могут относиться к редакции «После», это явно подписано.

Сверить пункт с загруженным оригиналом. Точный текст хранится независимо от интерпретации модели; сходство текста не доказывает потерю или дублирование.

## 1:30–2:30 · Новый расчёт и человек

Рабочее пространство доступно сразу, без входа. Первая локальная загрузка embeddings может занять больше времени — заранее подготовить кеш или явно выбрать lexical в .env перед стартом сервера. Модельный анализ остаётся Live.

Открыть перенос, включить подсветку отличающихся слов. Сохранить решение «Проверить» с комментарием. Показать, что машинное основание и человеческое решение разделены.

## 2:30–3:00 · Доказательства и воспроизводимость

Открыть HTML-отчёт. Показать приоритеты, цитаты, комментарий и паспорт запуска. Затем GitHub README с командами локального запуска. При недоступном API показать ошибку и ранее скачанный отчёт, не выдавая его за новый анализ.

## Дополнительная проверка реальных редакций

Оригиналы загружаются вручную и не входят в репозиторий. Контрольные связи: 5.4.4 → 5.3.3 — перенос; 9.37 — изменение адресата; 12.1.4 — изменение явной отчётности. Наличие трёх якорей не доказывает правильность всех остальных выводов. Полный Live-прогон большой пары остановлен по решению владельца ради срока сдачи; его успешность не заявляется.

## Live (вне обязательных трёх минут)

На выбранном изменении задать вопрос «Почему это перенос, а не потеря?». Показать источники и журнал инструментов. Ошибка API не заменяется фиктивным ответом.
