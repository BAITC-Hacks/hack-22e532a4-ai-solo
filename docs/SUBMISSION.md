# HackAlem AI — BaqBaq

## Решение

BaqBaq превращает ручную сверку организационных положений в evidence-first workflow: файлы «до/после» → карта структуры → матрица функций → риски → источники → проверка сотрудником → экспортируемое заключение.

## Доказательства по критериям

| Критерий | Баллы | Доказательство |
|---|---:|---|
| Соответствие задаче | 25 | Основной сценарий работает на предоставленной паре; пять must-have представлены в UI/API |
| Техническая реализация | 25 | OOXML/PDF/XLSX ingestion, SQLite exact layer, semantic layer, resolver, trace, live adapter |
| README и воспроизводимость | 25 | `run.ps1`, `verify.ps1`, pinned requirements, 17 tests, 24-case evaluator |
| Ценность и применимость | 15 | Один экран аналитика, точные цитаты, review history, HTML/Markdown report |
| Потенциал и оригинальность | 10 | Двухслойная память, отказ от недоказанных выводов, человек поверх immutable AI finding |

## Честный статус

- Offline основной путь: реализован и проверен.
- Live model: adapter реализован, без credentials не запускался.
- DOCX/PDF/XLSX: smoke и parser tests выполнены; OCR и legacy Office не заявлены.
- Контрольный набор: 24/24 PASS; это internal evaluation.

## Данные

Предоставленные организатором документы не включены в Git. `.env.example` содержит только локальные пути подключения. Репозиторий хранит код и синтетическую разметку, но не исходные документы.
