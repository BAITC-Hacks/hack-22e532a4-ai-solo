# BaqBaq — описание для сдачи

## Название

BaqBaq — проверяемая сверка организационных изменений

## Краткое описание

BaqBaq сравнивает документы до и после реорганизации, находит изменения функций и потенциальные риски. Каждый вывод связан с точными источниками; сотрудник проверяет основания, фиксирует решение и экспортирует заключение.

## Технологии

Python, FastAPI, SQLite, JavaScript, FastEmbed, ONNX Runtime, OpenAI API, DOCX, PDF, XLSX.

## Отправка

1. Проверить финальный код в выданном репозитории BAITC-Hacks/hack-22e532a4-ai-solo.
2. На платформе выбрать кейс Казахтелекома, заполнить название, описание и теги.
3. Нажать «Сдать решение» и убедиться в подтверждении отправки.
4. Дедлайн на предоставленной форме: 23 сентября, 18:00; часовой пояс отдельно не указан. После дедлайна push блокируется.

Push не равен отправке формы. Этот файл не утверждает, что заявка уже отправлена. Инструкция не требует отдельного видео/презентации в показанной форме; для финалистов может быть отдельный регламент.

Оригиналы организатора и API-ключи не включены в Git. Данные открытого демо явно синтетические.
