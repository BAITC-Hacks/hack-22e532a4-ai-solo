# Ограничения

- Выводы ограничены загруженным комплектом и требуют проверки сотрудником. Наличие точной цитаты не гарантирует правильность интерпретации.
- Live API прошёл серверный smoke-тест на синтетической паре (анализ, вопрос, отчёт). Полный Live-прогон исходных документов и независимая оценка качества ещё не выполнены.
- Offline-извлечение, перенос, split/merge и риски остаются эвристическими. Нет полной независимой разметки реальной пары и измеренной точности по всем рискам.
- FastEmbed локальный, но для первого запуска требует загрузки весов. Модель: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2; библиотека 0.7.4. Весовой артефакт upstream отдельно не закреплён commit-хешем; для полностью автономной сдачи нужно сохранить разрешённый кеш модели.
- При явно выбранном lexical-режиме нейронный поиск не выполняется.
- Явное текстовое указание преобразования 1:1 распознаётся при точном упоминании обеих сторон; отрицания и проекты не подтверждаются. Юридическая реорганизация и дата вступления редакции в силу не устанавливаются по близким названиям. Нет полноценного графа подчинённости и анализа исключений независимости.
- Live-сопоставление получает до пяти лучших кандидатов на старую функцию. Отсутствие принятой пары остаётся UNKNOWN; не доказательство потери.
- OCR, legacy DOC/XLS и DOCX/PDF-экспорт не реализованы. PDF поддерживает текстовый слой; сложные колонтитулы, вложенные таблицы и нестандартные схемы могут требовать ручной проверки.
- Excel поддерживает строки с явным владельцем и функцией; произвольные многоуровневые оргсхемы не гарантированы.
- Извлечение live ограничено 2000 фрагментами на сторону. Размер файла ограничен 25 МБ. Нет промышленного лимита вычислений для больших наборов.
- Нет автоматического восстановления прерванного запуска; повторный анализ создаёт новый run. API создания сравнения идемпотентен, остальные операции не заявлены как exactly-once.
- Новые review-решения дополняют историю старого finding; машинные findings старого run не изменяются. API и UI показывают последний review, также доступна история.
- Нет MCP, внешних нормативных проверок, бенчмаркинга других операторов и enterprise IAM.
- Live-модель получает текст источников. Не заявляется pre-LLM обезличивание или гарантия отсутствия передачи данных провайдеру.
- Синтетические 24 сценария — встроенная инженерная проверка. 24 старых probe-теста строк не являются метрикой обнаружения рисков.
