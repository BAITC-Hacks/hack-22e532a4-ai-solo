# Ограничения

- Анализ видит только загруженные комплекты. «Не найдено» не означает «утрачено в компании».
- Два положения не являются полным основанием для юридического вывода о создании подразделения или дате вступления редакции в силу.
- Offline semantic index — детерминированный subword/concept matcher, не нейронный encoder. Он воспроизводим на CPU, но хуже понимает дальние перефразировки.
- Live LLM adapter реализован, однако без пользовательских credentials его сетевой путь помечен `NOT TESTED`.
- DOCX pagination не угадывается: локатором служат пункт, абзац или таблица. PDF использует страницу, XLSX — лист и диапазон.
- PDF без текстового слоя требует OCR. OCR, legacy DOC/XLS и защищённые документы не поддерживаются.
- Формулы XLSX читаются как сохранённые значения; пересчёт книги не выполняется.
- Markdown и HTML экспорт реализованы. DOCX/PDF экспорт оставлен за границами MVP.
- Возможное дублирование и потенциальный конфликт интересов — индикаторы для проверки, а не утверждения о нарушении.
- 24 cases — включённая инженерная проверка, а не независимый benchmark. Реальная пара используется как regression data, синтетические положительные классы не выдаются за факты компании.
